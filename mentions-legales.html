1. Éditeur du site1. Publisher

Le site « La Grande Muraille de Chine » est un prototype étudiant réalisé dans le cadre de la formation BUT Informatique à l'IUT de Marne-la-Vallée — Université Gustave Eiffel. Il est présenté sous la marque pédagogique M.C.N. pour un projet de médiation culturelle et numérique.The website “The Great Wall of China” is a student prototype created as part of the BUT Informatique programme at the IUT de Marne-la-Vallée — Université Gustave Eiffel. It is presented under the educational brand M.C.N. for a cultural and digital mediation project.

Responsable de la publication : équipe de projet M.C.N.Publication manager: the M.C.N. project team.

Le site est destiné à être hébergé localement, sur GitHub Pages ou sur une plateforme académique dans le cadre d'un rendu universitaire. 5. Données et stockage local5. Data and local storage

Le prototype ne possède pas de base de données serveur. Les préférences de confort, le passeport patrimoine et le carnet de route sont mémorisés localement dans le navigateur via localStorage. Ces informations restent sur l'appareil de l'utilisateur.The prototype has no server-side database. Comfort preferences, the heritage passport and the route notebook are remembered locally in the browser through localStorage. This information stays on the user's device.
